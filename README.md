BMI Calculator

A simple and responsive BMI (Body Mass Index) Calculator built using HTML, CSS, and JavaScript. This project allows users to calculate their BMI by entering their weight and height and instantly displays the result along with the BMI category.

Features
Easy-to-use interface
Instant BMI calculation
Displays BMI value
Shows BMI category (Underweight, Normal Weight, Overweight, Obese)
Responsive design
Built with pure HTML, CSS, and JavaScript
How BMI is Calculated

BMI is calculated using the formula:

BMI = Weight (kg) / Height² (m²)
BMI Categories
BMI Range	Category
Below 18.5	Underweight
18.5 – 24.9	Normal Weight
25.0 – 29.9	Overweight
30.0 and above	Obese
Technologies Used
HTML5
CSS3
JavaScript
Usage
Enter your weight in kilograms (kg).
Enter your height in meters (m).
Click the Calculate BMI button.
View your BMI result and category instantly.
